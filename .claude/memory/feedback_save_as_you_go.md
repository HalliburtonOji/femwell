When producing any substantive deliverable in a conversation — brainstorms, research notes, design rationales, roadmaps, plan documents — save it to the workspace folder (`/sessions/relaxed-loving-brahmagupta/mnt/femwell/` or the relevant subfolder) and update the appropriate auto-memory entry **as you produce it**, not at the end of the session or only when asked.

**Why:** User said "always save as you go" on 2026-04-20 after I produced a 10-feature brainstorm only in-chat and they had to explicitly ask me to save it before pivoting to the next request. Conversational-only work is effectively lost the moment the chat scrolls.

**How to apply:**
- Brainstorms, lists of ideas, roadmap thinking → save as `.md` in the workspace folder alongside code/HTML work
- Design rationales, research briefs → save as `.md` next to the HTML demos they explain
- Strategic decisions the user accepts → snapshot as a project-type memory file
- Always include a computer:// link in the chat reply so the user sees the save happened
- For pages redesigns where I'm iterating, save snapshots before major pivots, not only at sign-off
- Don't ask permission to save — just save. The user can delete later.
