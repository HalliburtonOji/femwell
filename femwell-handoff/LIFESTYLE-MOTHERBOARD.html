Lifestyle — the motherboard

An exhaustive map of every part of Lifestyle, a deep focused brainstorm of each, brand-new whole-life pieces that should exist, and a rebuilt granular build order that supersedes the old thin plan. Plan/brainstorm only — nothing built this pass. 2026-07-15.

Orientation

Lifestyle is FemWell's whole-life room — "your life in bloom," not a content feed and not a cycle tracker with articles bolted on. Today it's a good skeleton running well below its potential: a flora hero, a SummaryCard, a (new, personalised) big-card Reads deck, and five clipboard boards — but most boards are one-line lists, two of the app's richest readers are dark, the whole-life domains (movement, rest, beauty, home, money, creativity, relationships, nature, joy) are barely present, and there's no daily reason-to-return ritual.

Already done & LIVE (pieces 1–4, this build stream): 1 FloraCover the in-app ecosystem cover system · 2 Article deck big-card showcase deck · 3 Live drop-in deck on the real page · 4 Personalisation getLifestyleFeed + recordLifestyleAction wired (interests + behaviour + gentle phase, privacy-safe). This doc plans everything after.

Legend: rich/live thin dark (built but unmounted) new done needs backend

B · Deep brainstorm — every piece, made rich

For each part: now → thin/broken → depth (real mechanics + content + craft) → additions → onboarding → return nudge → why she returns. Brand-anchored (BRAND_IDENTITY §6.7 cards, §6.8.2 structure, §4–5 flora, §10 living ecosystem).

Depth: make it the §6.8.2 tap-to-rebloom controller — 5 whole-life destinations (Read · Listen · Story · Sky & slow · Move/Feel) that rewrite the title, re-tint the colourway, and re-bloom one→many. The hero flower becomes hers (Bloomprint fingerprint) and shifts with the season and time of day (dawn/dusk light). Drop the second bouquet. Return: the hero visibly changes with her cycle/season/mood so the page feels alive and personal every open.

Cross-cutting: covers, empty states, motion, voice

  • Covers: FloraCover (done) everywhere a stock image was — articles, stories, books, the reel, LifestyleDetail hero. Retire stock across the domain.

  • Motion (§6.9): hero one→many bloom on tap; gentle card-in on scroll; the pollinator drifts; reduced-motion safe. Never bouncy.
  • Voice (§10.5): warm smart-friend, whole-life, never clinical; life-stage tints, never dominates.

D · Brand anchor, backend flags & the rebuilt build order

Brand anchor

Every piece builds to BRAND_IDENTITY.md: the §6.8.2 canonical page template (top chrome → flora hero + controller cards → glance⇆Jess row → clipboard boards → handy row → closing); the §6.7 card language (typed cards, hook + line + inline action, no dumb containers, FloraCover on top); §6.7.6 quick-action popups for micro-tasks; §4–5 flora + §10 living ecosystem (fauna, seasons, the soulful whole-life voice); one calendar overlay (§6.8.1). Cards are big and considered, never cramped tiles.

Backend flags (50-fn cap — currently ~118 fn dirs; add nothing without sign-off)

  • Reuse, no new backend: restore readers, personalise boards, de-hardcode/rotate, Move, Mirror, Nest, Outside, Curious, Almanac, Becoming, Mood presets, Garden tie, real media (existing ingestion fns).
  • New ENTITY (small, no fn) — sign-off: LifestyleCollection (my shelves) · optional LifestyleRitual / MakerLog / KindredNote / JoyMoment / MoneyMoment (several could reuse Journal instead — prefer reuse).
  • New FUNCTION — hard flag: generateLifestyleDigest (the Sunday letter) and possibly an audio-digest assembler. Given the cap, prefer riding existing weekly/voice fns or a cron already present; do NOT add without explicit sign-off.
