One exact unfinished object with its real reader/page/episode state. No continuation exists: begin directly with actual keeps. A bookmark marker means a stored place; a forget-me-not marks collection continuity, not an invented personal souvenir.

Archive entry

Title, content kind, source/version, real saved date if available, short genuine excerpt and direct Open / Resume / Play. Unknown kinds remain visible with appropriate source/error handling. One removal control is separate from opening.

Mixed versus grouped

Recent dated items can be mixed in one reading lane. Existing categories remain available; filter/search only narrows, never deletes or migrates. Undated legacy keeps stay in their own truthful group. Empty search preserves other collections.

Annotations

Her own note is shown only from real stored content and clearly distinguished from source text. Quote/version context lets an exact passage return survive revised content. Unmatched passage stays recoverable. No AI narrative about why she saved it.

Removal / failure

Pending disables only the affected object, retains old view on failure and reports partial store success honestly. If destructive removal needs confirmation, use the existing recovery contract. Do not advertise Undo without an actual reversible operation.

Recommendations

Keep the current phase set, explicitly separate from saved things. It never inflates saved count or pretends she chose it. Whole-life subject relevance still comes from actual interest/history, not a clinical default.

Material continuity

Different sizes earn different jobs: one bookmarked return, then a narrow index with aligned provenance; category dividers use quiet archive leaf edges. No flower wallpaper, scrapbook clutter or fabricated dates. An occasional pressed outline can identify a saved section, not every item.
