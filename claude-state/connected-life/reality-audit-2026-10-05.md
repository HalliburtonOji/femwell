7. **Goal.next_action / BucketItem.steps + chosen task:** schedule one chosen next action, then deliberate completion updates the correct intention. No new goals tracker or invented progress.
8. **Current event + RSVP + existing pod:** optional accepted attendance plan and exact event return. Fix event identity/freshness before fan-out.
9. **Observed pattern + supporting dates + selected experiment:** private evidence panel, chosen change, later reflection with sample/missingness stated. No causal or lunar-health claim from coincident dates.
10. **Public lesson + chosen observation time:** save exact lesson/version; accepted observing plan appears in existing Today/Planner slot and returns there. No automatic chart/cycle/private-note disclosure.
