# X motion-stack reference → FemWell decision, 14 October 2026

The [linked X post](https://x.com/skunzu/status/2110097012339200134) is a promotional list of ten open-source web libraries framed for Claude. Its attached 16-second video is a recording of a repository list; it is not a demonstration of a finished motion design, measured mobile performance or a Codex-only skill. The post links to a separate sales pitch for a 20-second launch clip. Treat its star counts and performance claims as marketing, not a build specification.

The ten named projects: [Three.js](https://github.com/mrdoob/three.js), [Motion](https://github.com/motiondivision/motion), [Fabric.js](https://github.com/fabricjs/fabric.js), [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm), [deck.gl](https://github.com/visgl/deck.gl), [canvas-confetti](https://github.com/catdad/canvas-confetti), [drei](https://github.com/pmndrs/drei), [cobe](https://github.com/shuding/cobe), [twgl.js](https://github.com/greggman/twgl.js), [Rive runtimes](https://github.com/rive-app/rive-runtime). These are normal JavaScript tools Codex can design/code with; no Claude dependency is implied.

**Keep and use selectively:** FemWell already depends on `framer-motion`, `three` and `canvas-confetti`. Existing CSS already gives the Sky morning-glory restrained movement and a reduced-motion fallback. The first visual experiment should use existing CSS/Framer Motion for one purposeful interaction: the selected flower/Moon response or an inline card-to-reader transition, compared on iPhone-shaped 360/390/430. Measure bundle, frame stability, tap latency and reduced-motion behaviour. This is a candidate in Ideas, not an app-wide animation retrofit.

**Defer:** Three.js/drei/twgl would be justified only for a separately approved interactive Sky instrument that beats the existing layered art on actual phones and degrades gracefully. Rive needs an authored state-machine asset and a concrete user job. Fabric.js is for a canvas editor; ffmpeg.wasm is browser-side media processing; deck.gl is a data visualisation engine; cobe is a globe. None addresses a content recommendation, provenance or dead-link defect. Confetti is already installed but repeated reward bursts conflict with FemWell's no-scoreboard/guilt tone; use only for a meaningful, consented celebration if Halli wants one.

**Codex counterpart:** a short repo-local on-demand skill at `.agents/skills/femwell-content-design/SKILL.md` describes the specific audit/design flow. It does not install ten packages or re-run a critic. [Official OpenAI guidance](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra) says excessive skill descriptions and blanket AGENTS instructions bloat context; keep the skill narrow and read source files only for the active atom. Existing paused automation stays paused. This is usage discipline, not a claim about account-token savings.
