## Detail seeds worth testing, not adding everywhere

- **A line travels:** passage → private note → intentionally shared public passage → conversation → exact source. Same object; annotation failure stays visible.
- **A chapter meets an episode:** only a real editorial subject/author/book reference can join them, with a labelled relationship and exact timestamp. A matching phase tag is insufficient.
- **A lesson keeps its date:** tomorrow changes the deck; kept edition remains. Replies return there; reflection stays private.
- **A plan speaks back:** the activity face shows the accepted Planner time with Edit/Undo, not a second scheduling prompt; failed write leaves her choice intact.
- **Small surprises carry work:** a ribbon marks actual resume; an acoustic crease holds transport; a folio number identifies a real edition. None is a pretend control or extra reading task.
