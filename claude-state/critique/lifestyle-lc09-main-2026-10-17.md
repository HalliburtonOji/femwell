## Focused research and design rationale

- [NN/g mobile progressive disclosure case study](https://www.nngroup.com/articles/vanguard-mobile-app/) documents keeping common mobile tasks direct while moving depth behind intentional disclosure. Here the first room choice and one meaningful action stay visible; complete library, notes and secondary tools remain available in a single labelled layer rather than stacked first-fold prose. This is a design inference for FemWell, not evidence of user satisfaction.
- [W3C modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) specifies focus containment, Escape and return of focus. Use existing calm dialog owner for sheets and verify open/close; do not invent another modal primitive.
- [W3C disclosure pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) supports clear expand/collapse state. A cue labelled as a destination must open the disclosure itself; scroll-only is misleading.
