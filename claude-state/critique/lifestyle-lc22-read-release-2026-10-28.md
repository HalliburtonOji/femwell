## Specific research and factual checks before implementation

[W3C’s button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/) requires named keyboard activation; a clickable `div` fails that path. A native source link is the appropriate element when the action opens another site. [GOV.UK’s UI writing guide](https://www.gov.uk/service-manual/design/writing-for-user-interfaces) supports a short, literal exit and an honest unavailable state rather than repeating more explanatory copy. [ONS’s user-needs to content process](https://service-manual.ons.gov.uk/content/writing-for-users/user-needs) explicitly includes peer and stakeholder review before publication, which supports keeping anonymous agent drafts in Ideas. These are design inferences, not a measured FemWell satisfaction result.

The [MoneyHelper Direct Debit guide](https://www.moneyhelper.org.uk/en/everyday-money/banking/direct-debits-and-standing-orders) still says stopping the payment does not cancel a contract and describes the guarantee. [Ofgem’s October–December 2026 price-cap page](https://www.ofgem.gov.uk/your-energy-supply/your-energy-bill/energy-price-cap-unit-rates-and-standing-charges) still says £1,723, up 4%, for its specified illustration, and [Ofgem help](https://www.ofgem.gov.uk/your-energy-supply/your-energy-bill/get-help-your-home-or-business-energy-bills) lists supplier help. This is a source-availability check on 28 October, not an editorial sign-off or promise the news stays current. The existing 14-day date gate means it needs a fresh check before staying in a later issue.
