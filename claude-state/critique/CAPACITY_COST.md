## Current primary research — checked 7 October 2026

- [Base44 credits](https://docs.base44.com/Account-and-billing/Credits): own database reads/writes do not consume integration credits. Where applicable, backend invocations use approximately one credit per 100 calls; actual workspace billing can differ. Built-in AI/media/messaging work and external services require separate accounting. Use workspace usage and real external invoices before projecting spend.
- [Base44 pricing](https://base44.com/pricing): plan allowances and published prices are not supported concurrent-user guarantees; our actual subscription is not established here. No conversion to a promised £ budget.
- [Runtime troubleshooting](https://docs.base44.com/Community-and-support/Troubleshooting): cache, batch and delay retries; runtime limits are person-scoped. [Apps API limits](https://docs.base44.com/developers/references/apps-api/get-started/rate-limits) concern workspace/PAT management: do not apply their numeric entity-list limit to end-user SDK traffic.
- [Entity pagination/projections](https://docs.base44.com/developers/references/sdk/docs/type-aliases/entities): supports cursor pagination and fields. Installed frontend SDK0.8.51 already implements them; backend pinned SDKs must be inspected separately. Cursor avoids shifted offset boundaries during concurrent additions/deletions. A future migration still needs full-history/no-strip proof.
- [Base44 app performance](https://docs.base44.com/Performance-and-SEO/App-performance): measure published mobile behaviour; split large scripts, compress assets and defer offscreen work. Preserve all art/routes/documents.
- [TanStack query defaults](https://tanstack.com/query/latest/docs/framework/react/guides/important-defaults): mounting/reconnection can refetch stale queries. Our query client already disables window-focus refetch and sets retry1; generic default retry3 claims would be wrong.
- [React fetching in effects](https://react.dev/reference/react/useEffect#fetching-data-with-effects): ignore obsolete responses after cleanup. Applied to exact owner/phase feed and owner-scoped keep reconciliation.
