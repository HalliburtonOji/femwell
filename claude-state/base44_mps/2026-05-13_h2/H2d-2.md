# H2d-2 — Paid Shelf (£19/£29/£55) + OneShotPurchases + simulated Stripe

> Paste everything below the rule into the base44 builder.

---

Paid Surface 2 — three one-shot products on a horizontal shelf. UK pricing in £. No real Stripe keys required to ship — the UI uses simulated checkout that flips to live when real price IDs land in env.

**Rules:** UK English. £. No emoji codepoints. Attribution chip "Backed by Astra Cole, MA, FAS" on all three.

1. SCHEMA — create entity `OneShotPurchases`:
   - `user_id` (string, required)
   - `product` (enum: `year_ahead` | `chart_atelier` | `choose_the_day`)
   - `price_pence` (integer — 1900 / 2900 / 5500)
   - `stripe_session_id` (string, optional)
   - `stripe_payment_intent_id` (string, optional)
   - `status` (enum: `pending_payment` | `paid` | `delivered` | `refunded` | `simulated`)
   - `delivered_payload_url` (string, optional — for the PDF or unlock link)
   - `created_at` (date-time)
   - `paid_at` (date-time, optional)
   - `delivered_at` (date-time, optional)

2. CREATE `base44/functions/createOneShotCheckout/entry.ts`:
   - Wraps `stripeCheckout` for `mode: 'payment'` one-shots.
   - Accepts `{product: 'year_ahead' | 'chart_atelier' | 'choose_the_day'}`.
   - Reads `STRIPE_YEAR_AHEAD_PRICE_ID`, `STRIPE_CHART_ATELIER_PRICE_ID`, `STRIPE_CHOOSE_THE_DAY_PRICE_ID` from env.
   - If the relevant price ID is missing, write a `OneShotPurchases` row with `status: 'simulated'`, return `{simulated: true, message: "Coming soon — your interest has been logged."}`. The card will deep-link to a "thank you for your interest" page on the frontend.
   - If the price ID is present, create a one-time Stripe `checkout.session` (mode: 'payment'), write a `OneShotPurchases` row with `status: 'pending_payment'` and the `stripe_session_id`, return `{simulated: false, checkout_url}`.

3. EDIT `base44/functions/stripeWebhook/entry.ts`:
   - Handle `checkout.session.completed` for the three one-shot product SKUs.
   - On `paid` event: update the matching `OneShotPurchases` row to `status: 'paid'`, set `paid_at: now()`.
   - For `year_ahead` and `chart_atelier`, trigger a delivery function (a new LLM job that generates the PDF) — schedule it via the orchestrator with phase `deliverOneShot`.

4. REWRITE `src/components/horoscope/sections/PaidShelf.jsx` per demo §7.5:
   - Three cards in a horizontal scrollable row (snap-x).
   - Each card has the same shell: Plum Night background, accent corner ribbon with price (£19 / £29 / £55), Fraunces 17px title, italic 12px sub-line, four-line specimen italic, bottom-right CTA pill linking to `createOneShotCheckout` with the right product.

   - CTA: `Get my Year Ahead · £19`
