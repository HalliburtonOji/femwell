# H2d-1 — Atelier Reading paywall + AtelierLetters entity + monthly draft cron

> Paste everything below the rule into the base44 builder.

---

Paid Surface 1 — the Atelier Reading. Long-form monthly letter, AI-drafted, human-signed by Astra.

**Rules:** UK English. £. No emoji codepoints. **Attribution chip says "Backed by Astra Cole, MA, FAS"** — NOT "Backed by Skyfield" (see H2_DECISIONS.md D2). Real ephemeris is H3 territory.

1. SCHEMA — create entity `AtelierLetters`:
   - `user_id` (string, required)
   - `month` (string, "YYYY-MM" format)
   - `title` (string)
   - `body_html` (string — rich text with headings/paragraphs)
   - `draft` (boolean, default true)
   - `published_at` (date-time, optional)
   - `signed_by` (string, default "Astra Cole, MA, FAS")
   - `created_at` (date-time, default now)

2. CREATE `base44/functions/draftAtelierLetter/entry.ts`:
   - Monthly cron-driven LLM draft.
   - For each user whose `Entitlements.plan` is `plus` / `pro` / `premium` AND who lacks an `AtelierLetters` row for the current month, generate a long-form letter (~1200 words).
   - Inputs to the LLM: birth chart, current month's profection, current month's major transits, last 3 months' cycle pattern, user preferences (Quiet Mode, Soft Sky).
   - Output schema: `{title: string, body_html: string}`.
   - Save with `draft: true` and `signed_by: "Astra Cole, MA, FAS"`.
   - Send a notification to the operator: "Atelier letters awaiting sign-off for {n} users."

3. EDIT `base44/functions/pipelineOrchestrator/entry.ts` — add a new phase `draftAtelierLetters` gated by `wantsPhase('draftAtelierLetters')`. Schedule to run on the 1st of each month after `computeRedWhiteMoon`.

4. CREATE `src/components/horoscope/hooks/useEntitlements.js` — reads `Entitlements` row, returns `{ plan, hasAtelier }` where `hasAtelier = plan in ['plus', 'pro', 'premium']`.

5. REWRITE `src/components/horoscope/sections/AtelierReading.jsx` per demo §7:
   - When `hasAtelier === false`: locked variant.
     - Plum Night card with eyebrow "ATELIER · BACKED BY ASTRA COLE, MA, FAS"
     - Fraunces 22px Title: "Your monthly letter from Astra is in the studio."
     - Italic body: "Long-form, signed, sent on the first of every month. Built from your chart, your cycle, and the month's sky — not a template. Reads like a New Yorker science feature, not a horoscope."
     - Three-line specimen excerpt (Fraunces italic, slightly transparent) so the user can see the voice.
     - CTA pill `Unlock the Atelier · £8.99/month` — opens stripeCheckout for the existing Plus subscription. NO real Stripe keys required to ship — if `STRIPE_PLUS_PRICE_ID` is missing in env, render with `simulated=true` and warn the operator in console.
     - Renewal terms line below: "Renews monthly. Cancel anytime in Settings."
   - When `hasAtelier === true`:
     - Unlocked variant: same card, but no CTA.
     - Pulls latest `AtelierLetters` row where `draft === false` (i.e. operator-signed).
     - If a `draft === true` row exists for the current month, show a small banner "Awaiting Astra's sign-off — usually published by the 3rd."
     - Renders `title`, `body_html` (sanitised), and the sign-off "— {signed_by}".

6. EDIT `base44/functions/stripeCheckout/entry.ts` — no behaviour change for Plus subscriptions, but ensure the success page handles a return-to-Horoscope deep link.

7. SCREEN — under the Atelier card on the live page, add a small admin-only panel (visible only when `user.is_operator === true`) that lists draft letters and lets the operator click "Publish letter" to flip `draft: false` + set `published_at: now()`. This panel renders an extra item in the existing operator menu rather than a new page.

VERIFY:
- Free users see the locked Atelier card with the £8.99 CTA and three-line specimen.
- Plus users with a published letter see the long-form body, signed Astra Cole, MA, FAS.
- Plus users with only a draft row see the "Awaiting sign-off" banner.
- Operator can flip drafts to published from the operator panel.
- Cron emits an Atelier draft for each Plus user on the 1st of each month.
- Attribution chip reads "Backed by Astra Cole, MA, FAS" — NOT "Backed by Skyfield".

Run the build, then publish.
