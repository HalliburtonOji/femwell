Appendix — the safety mechanics behind Panic Mode

Panic Mode is the single most load-bearing feature for trust. It has to work offline. It has to bypass notification settings and quiet hours. It has to never crash. Every visual decision below follows from those three constraints.

Design rules

  • No red. Red is triggering during panic. Luteal plum + rose-300 + cream only.
  • No countdowns. A 3-min timer feels like pressure. Cycles shown, time estimated, never enforced.
  • No alarm language. "Call now", "emergency", "crisis" all replaced. "Reach someone", "stay with me", "come back".
  • Exit always one tap. Top-right ✕ visible on every screen — no hold-to-confirm.
  • Full-screen immersive. No bottom nav, no header, no chrome.
  • Dark backgrounds in phase 1–4, dawn in phase 5 — visual metaphor for coming through.

Entities written during a panic session

  • PanicLog — id, started_at, ended_at, techniques_used[], cycle_day, phase_at_time.
  • PanicAfterglow — felt_sense enum, one_word optional, threaded_to_journal_id nullable.
  • PanicReaches — contact_id hashed, method (text/call), completed bool. Never stores contact content.
  • PrePanicCheck — optional, Jess sets after 3+ panics in same phase. Default off.
  • All five entities are E2E-encrypted on device. Reuse Sealed Letters / BodyPhotos key infrastructure — no new crypto.

Always-reachable rules

  • Quiet hours do not apply. Panic Mode button on Today is live 24/7.
  • Works offline. Breath, grounding, companion-voice cached. Only "reach someone" needs network.
  • Survives crashes. On relaunch, if unfinished PanicLog exists, show "still with me?" resume card.
  • No auth wall. If user is logged out, Panic Mode still accessible — logs queue locally until next login.
  • Panic Mode button appears on Today, Journal, Jess drawer, and Settings safety footer. Never more than one tap away.

Pattern noticed in four panic logs across this cycle, all luteal-phase evenings. Jess's Pre-Panic tool (from Jess v2 appendix) offers a gentle check-in on day 17 next cycle — one line, one question, skippable.

Escalation — what Jess will NEVER do

  • Never auto-dial anyone. Always user tap.
  • Never send a status to partner without explicit share — even with Partner Sync on.
  • Never display "this is an emergency" banners.
  • Never suggest a specific diagnosis ("panic attack", "PMDD episode"). Uses the word "this" or "now".
  • Never score panics on severity. Afterglow is felt-sense only, never 1–10.
  • Never summarise panic logs in the weekly digest unless user opts in.
