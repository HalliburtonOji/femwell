Appendix — how Explore fits the system

Rebuilt from the old dashboard-style Explore. No zodiac (that now lives on Lifestyle per the horoscope separation rule). No infinite scroll. Every surface returns to a Jess-picked opener, and every play writes to an entity so recommendations get smarter each cycle.

Entities new for Explore

  • ExploreItems — unified table: type (watch / read / listen), title, creator, duration, phase_tags[], life_stage_tags[], region_tags[], locked_to_pro.
  • ExplorePlays — user × item × ts × progress × paused_at × finished.
  • ExploreShelves — curator-authored groupings; Jess-overlay re-ranks within shelf by phase/goal.
  • Experts — Dr Aisha Patel, Dr Priya Shah, Dr Catherine O'Brien, Dr Brighten. Bio + region + credentials + topics.
  • AMASessions — scheduled live talks with question queue (QuestionSubmissions entity).

Ranking rules

  • Default sort for "For you" shelves = phase-match × goal-match × region-match × recency.
  • Continue where you left off beats anything else — pulls top 3 from unfinished ExplorePlays, any type.
  • No engagement-optimised feed. Items never re-ranked by "time on screen" or "scroll depth". Finished counts, paused counts, saved counts — not swipes.
  • New this week shelf is curator-picked, not algorithmic.
  • London / Manchester / Edinburgh voices are a dedicated shelf — not a tag buried inside.

What we removed from old Explore

  • Horoscope cards — moved to Lifestyle permanently.
  • Step counter dashboard — lives on Pulse.
  • "Trending" feed — replaced with editor-picked New This Week.
  • Infinite scroll — replaced with three horizontal shelves per tab.
  • Generic wellness stock photos — replaced with gradient covers + expert photos.
  • Notification permission prompt on first scroll — removed; only requested after 3 saves.

Jess-integration points

  • Hero pick is a Jess tool call: jess.pickForPhase({phase, goals, region}).
  • Jess-noticed line per tab — surfaced from ExplorePlays patterns.
  • "Teach me" button on any expert talk deep-links to Jess conversation with context preloaded.
  • AMA question submission can be drafted via Jess ("write this anonymously for me").
  • Saved-but-unfinished → weekend re-surface, only if user opts in during onboarding goals.

Ship order

Q2
ExploreItems entity + For-you / Watch / Read / Listen tabs + phase-tagged Jess hero pick.
Q3
Live AMA channel + QuestionSubmissions + Experts directory. Dr Aisha Patel as first live host.
Q4
"Voices from home" shelf (London/Manchester/Edinburgh contributors), Teach-me integration deep-links.

Ground rules

  • No zodiac, no astrology, no birth-chart — Lifestyle only.
  • No ads. Ever. Pro subscription is the monetisation.
  • No push notifications from Explore. Content comes to you via Today digest.
  • Every expert is credentialled — no wellness influencers without MD/PhD/RD.
  • All media saveable offline (Pro).
