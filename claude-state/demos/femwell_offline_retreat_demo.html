Engineering notes — Offline Retreat Mode

A low-bandwidth, low-pressure companion for retreats, travel, hospital stays, and dead-signal weeks. Reuses Sealed Letters cipher + queue. Nothing syncs without the user's tap. The panic path is always offline-capable.

Entities (base44)

RetreatPacks
  id, user_id, created_at, expires_at,
  pack_size_bytes, items_manifest_json,
  covers_date_range, phase_window_snapshot,
  wifi_only_download, sealed_state,
  media_bitrate ('lo'|'standard'),
  battery_budget_pct_per_day

PackManifest (item rows)
  id, pack_id, kind
    (jess_brief|program|prompt|ritual|audio|
     panic_script|pattern_dossier|community_cache),
  source_entity, source_id, bytes,
  required (bool), phase_band, day_offset,
  encryption ('e2e'|'local-only')

OfflineJournalQueue
  id, user_id, encrypted_blob,
  client_created_at (ISO), phase_band,
  kind ('journal'|'log'|'ritual_tend'|'afterglow'),
  partner_visible (bool, default false),
  sync_status ('queued'|'sending'|'sent'|'conflict'),
  conflict_with, last_attempted_at

SyncSessions
  id, user_id, session_start, session_end,
  items_synced, conflicts_detected,
  conflicts_resolved, bytes_uploaded,
  user_reviewed_before_post (bool)

RetreatSettings (per user)
  wifi_only_default, auto_pack_on_calendar_travel,
  panic_always_packed (always true),
  community_cache_optin, partner_notify_on_reconnect

Pack composer

  • Runs on setting_toggle or when calendar detects ≥3 consecutive travel days.
  • Picks items by phase overlap with pack window → always packs luteal + period support if window overlaps.
  • Lo-bitrate video path: 480p, 200kbps — 10min session ≈ 15 MB.
  • Cap: default 60 MB, hard ceiling 120 MB. Shows user what was trimmed.
  • Never packs: ads, growth notifications, analytics SDKs, 3rd-party trackers, Explore social content.

Cryptography

  • Reuses Sealed Letters keypair — server holds only public key, device holds private.
  • Offline journal entries encrypted on-device immediately, queued as opaque blobs.
  • Server cannot read content before, during, or after sync — it stores the sealed blob only.
  • Queue survives app kill, reinstall-from-iCloud, and SIM swap (tied to device keychain + biometric).

Reconnect flow

on network_reachable:
  if OfflineJournalQueue.any_queued:
    show ReconnectSheet     (not auto-post)
    build ConflictSet from
      (offline_log, partner_log_during_window)
    user taps "Sync all sealed"
      → fire sealed_letter_sync one-by-one
      → exponential backoff on failure
      → keep sealed blob locally until server
        confirms write (ack via message_id)
  else:
    silent background refresh only

Conflict resolution

  • Cycle data (period start, flow, symptoms): user wins unless user opts otherwise.
  • Care Bridge partner-logged events: if timestamps overlap, show side-by-side, let user pick.
  • Program progress: offline completions honored; duplicate-completes collapse.
  • Never merges journal text — always keeps both entries, dates preserved.

Panic path (always-offline)

  • Scripts, afterglow audio, breathing pacer, and sealed journaling all work in airplane mode.
  • Crisis line numbers cached locally per-country (999, UK 116 123, US 988).
  • Partner-notify on panic respects Retreat Mode — queues until reconnect unless user chose "notify even offline via SMS" in Partner Sync.

Surfacing rules

  • Pack prompt appears once per travel event; never nags a second time that trip.
  • Pre-flight card in Today if calendar shows "Travel" / "Flight" / "Retreat" event in next 72h.
  • During offline: banner on Today with day count + sync countdown; never red, never alarming.
  • Reconnect card ships once; dismiss-to-dashboard if user doesn't review in 24h (queue stays sealed regardless).
Never, in any form:
  • Auto-post journal entries on reconnect without user tap.
  • Show a "streak saved" or "you missed N days" framing.
  • Sync analytics events from the offline window (we truly don't record them).
  • Download anything over cellular without explicit "allow cellular" toggle.
  • Push marketing or Explore content into Retreat pack.
  • Expose offline journal content to Partner Sync or Care Bridge unless user opts per-entry after reconnect.
  • Retry-upload after 14 days — queue auto-seals to local-only and prompts user to decide.
