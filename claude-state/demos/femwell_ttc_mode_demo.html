Engineering notes — TTC Mode overlay

A Pro-tier overlay that adds fertile-window planning and three optional logs (BBT, cervical mucus, LH strips) without fundamentally changing the app. The guiding rule: TTC can be tender — every surface is designed so a hopeful month and a disappointing one both work.

Entities (base44)

TTCProfile (per user)
  id, user_id, enabled, enabled_at,
  months_trying, clinician_led (bool),
  help_goals[] (see-window|gentle-nudges|
    partner-understand|pattern-track|clinician-data),
  hard_month_mode_until (date),
  partner_sharing_scope
    (none|window-only|window+helps|full-peek-denied)

FertilityWindows (computed)
  id, user_id, cycle_id,
  window_opens (date), window_closes (date),
  peak_day (date), confidence_pct,
  method_used (calendar|bbt-calendar|bbt-lh|
    bbt-mucus-lh|clinician-override),
  updated_at

BBTLogs
  id, user_id, log_date, temp_c, time_recorded,
  sleep_hours_prior, disturbed (bool),
  device_source (manual|oura|apple|tempdrop)

CervicalMucusLogs
  id, user_id, log_date,
  consistency (dry|sticky|creamy|watery|egg-white),
  amount_note (light|mod|heavy), skip (bool)

LHStripLogs
  id, user_id, log_date,
  level (neg|low|rise|peak|fade),
  strip_brand (optional), photo_ref (e2e-encrypted),
  read_by (user|ocr)

TTCPartnerViewPrefs
  shows_window (bool default true),
  shows_peak_day (bool default false),
  shows_bbt (bool default false),
  shows_mucus (bool default false),
  shows_lh (bool default false),
  shows_helps_list (bool default true),
  shows_hard_month_switch (bool default false)

Window prediction

  • Baseline: calendar from last 3 cycles (± variance).
  • If BBT present: thermal shift triangulation → peak retro-confirmed.
  • If LH present: surge + 24–36h → peak forward-confirmed.
  • If mucus present: egg-white days ≈ fertile edge.
  • Confidence % based on signal count; surface uncertainty explicitly ("confidence 72% · high" — never hide it).
  • Clinician-override fields exist for TTC patients under care (hooks into Care Bridge).

Jess window-coach rules

render_ttc_message(context):
  // Allowed patterns
  allowed = ["window opens X", "peak arrives in N days",
             "what we learned this cycle", "soft reminder",
             "next cycle, here's what the body told us"]

  // Forbidden patterns (hard-blocked at template level)
  forbidden = ["you missed it", "best chance",
               "better luck", "try harder", "must",
               "most fertile day", "should have",
               "still not pregnant"]

  // Hard-month mode disables proactive check-ins
  if user.ttc_profile.hard_month_mode_active:
    return silent

  // Never schedule a "two-week-wait" dashboard
  if in_luteal_post_window:
    show_pulse_as_normal()   // no special UI

Partner Sync TTC on-ramp

  • Rides the existing Partner Sync tight-pipe; adds exactly 4 fields: window_opens_date, window_closes_date, peak_visible_to_partner (default false), what_helps_this_cycle.
  • Partner PWA (with.femwells.com) never sees: BBT charts, mucus logs, LH strips, BBT photos. Ever.
  • "She hasn't logged today" — never shown to partner.
  • Two-week wait period: partner dashboard shows nothing new. No "waiting" language, no countdown.
  • Hard-month switch invisible to partner by default; if shared, rendered as "she's taking a soft week."

Hard-month mode

  • One tap after a failed cycle silences the overlay for 21 days.
  • Planner fertile band fades to neutral. Window card replaced by "resting — come back when you're ready".
  • Jess stops proactive TTC messages. Base Jess (non-TTC) still answers user-initiated questions.
  • BBT/mucus/LH logging still works if user opens them — we don't hide tools.
  • After 21 days, we ask (once, quietly) "do you want the window back, or keep resting?"

Pro gating

  • Free tier sees the toggle but hits a paywall on enable.
  • Pro subscribers get the overlay + partner view + 3 logs.
  • Clinician-led users (Care Bridge active w/ fertility specialist) get the overlay free for the duration of the share.

Surfaces

  • Settings → TTC toggle (entry point).
  • Planner (re-skinned with fertile band when on).
  • Pulse (three new log types at top of luteal-cycle view).
  • Jess home (quiet coach card; never above morning briefing).
  • Partner PWA (tight-pipe fields, separate view variant).
Never, in any form:
  • "You missed it / best chance / must / should" phrasing anywhere in TTC surfaces.
  • Two-week-wait countdown, pregnancy-test reminders, or "are you pregnant yet?" prompts.
  • Share peak day to partner unless user explicitly toggles shows_peak_day.
  • Surface TTC badges, streaks, "N cycles tracked" achievement patterns.
  • Cross-user comparison ("couples who track BBT are X% more likely to conceive").
  • Ads or sponsored content anywhere in TTC Mode — full blackout.
  • Send TTC push notifications over cellular without opt-in; default is in-app only.
  • Sell or share TTC data to any third party; UK GDPR + DPA 2018 Article 2.2 sensitive-health-data path.
  • Auto-enable partner view; partner must be explicitly invited.
  • Show the overlay after a pregnancy is logged — switch to Early Pregnancy Mode quietly (that's a separate feature, not addressed here).
