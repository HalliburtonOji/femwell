The first ten minutes — so you feel met, not measured.

Ten screens. Low ask, high trust. We pick the life-stage upfront (Teen → Reproductive → Peri → Meno → Post-meno) so every downstream surface speaks the right language. Consent is explicit — the user chooses what Jess remembers before she starts learning. Payoff screen is a live preview of the first Today, not a generic "you're all set."

Appendix — how onboarding wires into base44

Onboarding collects the minimum to make the first Today feel tailored. Every answer writes to a real entity, gated by explicit consent. Ship order: stage picker + consent gates + first-Today preview in Q2; wearable gating + symptom templates in Q3.

Entities touched by onboarding

  • UserProfile — name, pronouns, life stage, region, primary language.
  • CycleProfile — last period, avg length, confidence flag.
  • UserGoals — max 3 goal tags; shapes Today feed ranking.
  • SymptomTemplate — curated one-tap chips surfaced on Today.
  • Integrations — wearable/calendar connections with per-source scope.
  • ToolConsents — Jess capability grants (remember/ask/draft/digest).
  • NotificationPolicies — 4 channels, quiet-hours window, per-channel cadence.

Friction budget (why this works)

  • 10 screens, median ~1:45 to complete in prototype.
  • Every screen is skippable except name + stage (needed for language).
  • Stage picker is inline — pattern notes risk A: locale must be visible, not buried in Settings.
  • Consent = separate toggles, not a big "Accept all". Aligns with risk B / memory-creep stance.
  • Payoff is a live preview, not a generic "all set" screen — instant proof of tailoring.

Ship order

Q2
Welcome · Name · Stage picker · Cycle · Goals · Consent gates · First-Today preview. Core flow.
Q3
Wearable connect (Oura + Apple Health only), symptom templates per stage, notification quiet hours.
Q4
A/B test stage-ordering, re-onboarding for returning users whose stage changed.

What we don't ask

  • Weight, BMI, calorie targets.
  • Sexual orientation.
  • Phone number (until push notif permission, which we delay until step 9).
  • Partner info (moves to Profile → Connections only if user opts).
  • Religion / astrology defaults (Lifestyle tab handles this).

Edge behaviour

  • No cycle (post-meno / pregnancy): skip step 4, replace with "Life season picker" — 12-wk named arcs.
  • Goal conflict: "Fertility" + "Panic tools" both on → Jess surfaces fertility gently, keeps Panic primary.
  • Multi-stage (Peri shifting into Meno): user can tick both; Today chooses dominant language but offers a "switch view" chip.
  • Back-nav: any answer editable from dots. No "are you sure" dialogs.
