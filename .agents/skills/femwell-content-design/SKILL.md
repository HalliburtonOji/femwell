For a requested content-flow change, read `AGENTS.md` and the current baton, then the relevant atom in `claude-state/critique/lifestyle-content-2026-10-14.md`. Inspect only the active routed surface, producer, handler and consumers. Measure usable records and direct actions before proposing another shelf. Preserve exact sources, histories and user capability; an item can leave a featured slot without deleting its library route.

Deliver one bounded room/atom at a time: specific research, one clear suggestion with an honest reason, direct consume/return, one optional browse choice, real mobile tap/pixel proof and a P0/P1/P2 self-critique. Stage in Ideas and record what is still unverified. Do not turn the workflow into a recurring audit or spawn parallel agents by default. Expensive generators, schedules, metadata providers and substantial product changes get a concrete review proposal before implementation. Use existing CSS/Framer Motion for justified motion; introduce another runtime only after a measured mobile prototype and reduced-motion path.
